## 店舗写真の登録

店舗写真は Supabase Storage の公開バケット `dealer-photos` に登録し、`public.dealers.photo_url` と対応付けています。既存の架空画像3枚をデモ店舗間で共用します。画像はすべて200KB以下です。

`search-dealers` が返す `dealer.photo_url` を画像の表示元にしてください。同じ店舗に複数の試乗車がある場合も同じURLを使い、車両ID・配列の位置・住所から写真を推測しません。未設定・読み込み失敗時はプレースホルダを表示します。画像は実在店舗の写真ではありません。

シードの店舗と写真の対応は `scripts/export-seed.ts` からSQLとJSONに同時に出力します。別のSupabaseプロジェクトに移行する際は画像をアップロードし、URLを新しい接続先へ変更してください。

## 車種画像の登録

10車種の参考画像を Supabase Storage の公開バケット `model-photos` に登録し、`public.models.photo_url` と対応付けています。`/rest/v1/models` の `photo_url` から取得できます。`dealer_vehicles.model_code` と `models.code` で対応させてください。シードの `models.json` にも同じURLを含みます。

モデルの参考画像であり、店舗にある個々の試乗車のグレード・ボディカラー・内装色を保証する写真ではありません。試乗車一覧で使う場合は「車種の参考画像」と表示します。未設定・読み込み失敗時はプレースホルダを表示します。
