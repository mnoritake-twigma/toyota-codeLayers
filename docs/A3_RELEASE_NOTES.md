## 実装メモ（B・C・D）

B（今回実装）: 車両の識別情報、取得範囲の明示、条件整合性、読み込み／0件／エラーの区別、
シード表示の拒否、電話案内、フィルタ処理の純関数化。既存 DS 部品・ユーティリティのみ使用。
新しい DS 部品・トークンは追加していない。

C（今回変更しない）:

- C1・中: 全件をたどれるページ契約、総車両数、条件に応じたグレード・色・エリアの候補と件数集計。
- C2・中: 店舗のエリアID、エリアマスタ、欠損を含むデータの整備とAPI提供。
- C3・中: 店舗画像の保存・対応関係・権利情報管理とAPIの参照項目。

D（見送り）: 住所・店舗名からのエリア推定、IDからの写真割り当て、全体取得保証のない総件数表示、
空き枠・仮押さえ・予約確定の表示、距離順・現在地検索の追加。
選べる対象は店舗に登録された1台、日時は希望として申し込む従来仕様を維持する。

`src/api/`、`supabase/`、接続先設定、送信 API は変更していない。
検索 API は既存のデモ用フォールバックを内部で保持するが、早期版の画面へは渡さない。
既存のモデル・県マスタとモデル選択画面は対象外として維持する。
